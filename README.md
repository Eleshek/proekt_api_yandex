# API Tests: Yandex Prilavok

Проект с автотестами для проверки параметра `name` при создании набора в API Яндекс.Прилавка.

Тесты проверяют позитивные и негативные сценарии для поля `name`: допустимую длину, недопустимую длину, разные типы символов, отсутствие параметра и неверный тип данных.

## Что проверяется

Проверяется ручка создания набора в Яндекс.Прилавке через API.

Основной фокус тестирования — параметр:

```json
{
  "name": "Название набора"
}
```

## Требования

Для запуска тестов должны быть установлены пакеты:

```text
pytest
requests
```

Установка зависимостей:

```bash
pip install pytest requests
```

## Запуск тестов

Запуск всех тестов выполняется командой:

```bash
pytest
```

## Проверки

| №  | Проверка                                    | Тестовые данные        | Ожидаемый результат                                                 |
| -- | ------------------------------------------- | ---------------------- | ------------------------------------------------------------------- |
| 1  | Допустимое количество символов: 1           | `"a"`                  | Код ответа `201`, поле `name` в ответе совпадает с `name` в запросе |
| 2  | Допустимое количество символов: 511         | Строка из 511 символов | Код ответа `201`, поле `name` в ответе совпадает с `name` в запросе |
| 3  | Количество символов меньше допустимого: 0   | `""`                   | Код ответа `400`                                                    |
| 4  | Количество символов больше допустимого: 512 | Строка из 512 символов | Код ответа `400`                                                    |
| 5  | Разрешены английские буквы                  | `"QWErty"`             | Код ответа `201`, поле `name` в ответе совпадает с `name` в запросе |
| 6  | Разрешены русские буквы                     | `"Мария"`              | Код ответа `201`, поле `name` в ответе совпадает с `name` в запросе |
| 7  | Разрешены спецсимволы                       | `"№%@"`                | Код ответа `201`, поле `name` в ответе совпадает с `name` в запросе |
| 8  | Разрешены пробелы                           | `" Человек и КО "`     | Код ответа `201`, поле `name` в ответе совпадает с `name` в запросе |
| 9  | Разрешены цифры                             | `"123"`                | Код ответа `201`, поле `name` в ответе совпадает с `name` в запросе |
| 10 | Параметр `name` не передан в запросе        | `{}`                   | Код ответа `400`                                                    |
| 11 | Передан другой тип параметра: число         | `123`                  | Код ответа `400`                                                    |
